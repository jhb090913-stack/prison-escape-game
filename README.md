# 탈옥: 마지막 야간 점호

브라우저에서 바로 실행되는 한국어 픽셀 아트 감옥 탈출 게임입니다. 별도 설치나 빌드 과정이 필요하지 않습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.

## 조작법

- 이동: `A` / `D` 또는 `←` / `→`
- 점프: `W` / `↑` / `Space`
- 다시 시작: `R`
- 모바일: 화면 아래쪽의 방향키와 점프 버튼

## 목표

발판을 건너 숨겨진 열쇠를 얻고, 순찰하는 경비를 피해 오른쪽 끝의 출구로 이동하세요. 경비에게 닿거나 바닥 아래로 떨어지면 작전 실패입니다.

## GitHub Pages 배포

1. GitHub에서 새 공개 저장소를 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 최상위에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치의 `/(root)`를 저장한 뒤 기다립니다.
5. 발급된 주소는 `https://깃허브아이디.github.io/저장소이름/` 형식입니다.

Google Fonts를 불러오지 못해도 게임은 실행됩니다.
